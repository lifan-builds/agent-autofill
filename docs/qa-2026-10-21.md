## Fixes supported by these checks

- The dashboard incorrectly capped record counts at 100. Counts now use the
  complete inventory, while tables explicitly identify their bounded previews.
- The popup enabled Fill without a selected request or manual handle. It now
  keeps the button disabled until there is something to fill.
- Expired requests could fill a username-only page. Expiry is now checked before
  any injection; the broker still independently enforces password-handoff expiry.
- Username delivery could target a new document after preflight. Both username
  and password delivery now require the original document identity.
- Reactive forms could replace or clear an input and still get a successful
  fill message. The helper now detects detached, hidden, or rejected fields and
  reports that the page changed. This failure was reproduced in a real DOM
  before the fix, then passed afterward.
- Attention items appear earlier, opaque group IDs are replaced by field labels
  in overview cards, section links reduce scrolling, and explanatory material is
  collapsible. Dashboard responses now use `Cache-Control: no-store`.
- CI now runs JavaScript behavior tests in addition to syntax checking.
- Malformed JSON request shapes no longer terminate the server. Unexpected
  backend errors return a generic message without provider details, and the
  next request can still succeed.
- Invalid Messages timestamps remain unknown instead of appearing newly sent.
- Failed Chrome snapshot copies and database opens remove temporary files.
- The IMAP date-boundary regression passes: recent messages from the previous
  mailbox day are considered, while the exact age filter excludes old codes.
- Repository-wide lint and type errors are resolved. Intentional error
  sanitization boundaries remain explicit and never log connector diagnostics.

## Repeat the browser checks

From the repository root, copy only the synthetic page and helper into a
temporary directory, then serve that directory on loopback:

```sh
qa_dir=$(mktemp -d)
cp tests/manual/login_fields.html "$qa_dir/index.html"
cp browser_extension/login_fields.js "$qa_dir/login_fields.js"
python -m http.server 8878 --bind 127.0.0.1 --directory "$qa_dir"
```

Open `http://127.0.0.1:8878` and choose **Run synthetic checks**. All nine rows
must say PASS. Stop the server with Ctrl-C. This exercises the actual field
helper in a browser page; it does not substitute for the
[installed-extension smoke check](extension-smoke-check.md).
