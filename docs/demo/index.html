Three Consent Boundaries

      

        

          
          
1. Value-free readiness

          
Inspect field counts and source health before any secret or profile value is unlocked.

        

        

          
          
2. Origin-bound handoff

          
Bind each grant to a single target origin and purpose with a short expiration window.

        

        

          
          
3. Revocable & non-acting

          
Revoke grants immediately after task completion; final form submission always stays with you.
