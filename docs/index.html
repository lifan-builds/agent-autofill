Every time an AI agent hits a form, you end up retyping your address, pasting a password into chat, or hunting down a verification code. Agent Autofill is a local-first personal vault for AI agents on your Mac. Start from Chrome: it organizes saved addresses, confirms Home versus Work, and remembers those meanings across tasks. When a site needs a login or a two-factor code, it hands off a one-time, origin-bound token and pulls the code from connected email or Messages so your raw password never enters model context. And before anything is submitted, you stay in control.

How it works

Three local boundaries keep credentials out of chat logs and keep form submissions human-approved.

1. Import locally from Chrome

Bootstrap saved addresses and logins into an AES-GCM encrypted SQLite vault with keys stored in the macOS Keychain—no plaintext CSV exports.

2. Pair MCP with scoped grants

Run agent-autofill mcp-install for Claude, Codex, Cursor, or Antigravity. Approve only the requested fields or use credential.use for an origin-bound fill.

3. Confirm before submission

The broker is strictly information-only: it never navigates, submits forms, or makes purchases. Your acting agent pauses for confirmation before clicking submit.
