# No-submit end-to-end evaluation run — 2026-10-10

This run exercised the local broker path and two public practice forms. Every
browser value was ephemeral synthetic data. No account was created and no form
was submitted.

| Case | Status | Evidence | Notes |
| --- | --- | --- | --- |
| Local broker + submission policy | PASS | In-memory broker returned one selected credential field; `always` and `non-financial` policy behavior was checked, including the financial override | Raw credential values were not printed or persisted |
| Selenium Web Form | PASS (no-submit) | Ordinary text, password-shaped synthetic value, textarea, checkbox, and radio were populated; page remained on `web-form.html` with Submit still available | Did not submit because the page reflects password-like values into a GET URL |
| Expand Testing registration | PASS (no-submit) | Synthetic username and matching password fields were populated; page remained on `/register` with Register still available | No test account or session was created |

## Safety findings

- The acting-agent confirmation gate was exercised in the local policy path.
- The browser runs stopped before the external submit control, as required.
- No Agent Autofill real profile, credential, OTP, payment, or financial value
  was transmitted to a third-party site. Using real saved values would require
  a separate action-time confirmation naming the exact destination and fields.
- Temporary browser tabs were closed after inspection.
